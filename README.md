🚀 SmartHub-React
A modern, responsive AI-powered productivity platform built with React. SmartHub-React combines multiple AI tools into a single workspace with a clean, responsive, and premium user interface.

✨ Features

- 🤖 AI Chat Assistant
- 🎨 AI Image Generator
- 📄 AI Resume Builder
- ✍️ Email & Content Writer
- 📑 PDF Tools
- 🔄 File Converter
- ☁️ Cloud File Storage
- 📝 Notes & To-Do Manager
- 🎓 Online Learning
- 💼 Job & Freelance Marketplace
- 🏢 Business Tools
- 📚 Blog & Articles
- 💱 Currency Converter
- 🧮 Calculator Hub
- 🌤️ Weather Forecast
- 📰 Live News

🛠️ Built With

- React.js
- JavaScript (ES6+)
- Tailwind CSS
- Lucide React

🚀 Installation

git clone https://github.com/syedhammads313-wq/SmartHub-React.git

cd SmartHub-React

npm install

npm run dev
